# BridgeLabz-SIPP-Training
This branch focused on deeper concepts of Java beyond the basics. I learned how object-oriented programming works in Java and how to structure real-world programs using classes and objects.

Key topics covered:

Classes, objects, and constructors

Method overloading and basic encapsulation

Inheritance and the super keyword

Understanding this keyword and access modifiers

Static vs instance variables and methods

Working with basic packages and organizing code

It gave me a solid understanding of how Java supports object-oriented design and reusability.
