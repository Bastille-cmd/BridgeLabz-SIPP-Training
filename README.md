# BridgeLabz-SIPP-Training
This branch was focused on mastering the four pillars of Object-Oriented Programming in Java. I learned how to design programs using abstraction, encapsulation, inheritance, and polymorphism to write more modular and maintainable code.

Key topics covered:

Abstraction using abstract classes and interfaces

Encapsulation through private fields and getter/setter methods

Inheritance and method overriding

Polymorphism: compile-time (method overloading) and runtime (method overriding)

Real-world examples applying all four OOP principles together

Importance of code reusability and flexibility in design

This branch helped me understand how to apply OOP concepts effectively in Java projects.
